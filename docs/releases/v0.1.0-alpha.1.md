# v0.1.0-alpha.1

Draft release notes. We have prepared this local alpha for review; no tag, GitHub release or AUR submission exists yet.

eDEX-UI TUI reconstructs parts of eDEX-UI with native tmux shells, Kitty graphics and Yazi. We use the security-patched upstream as the visual reference. This release does not claim an exact reconstruction of the film interface.

## Included

- Five shell slots that preserve their processes and working directories when switching.
- Live Linux System and Network instruments, the upstream globe mesh and memory grid.
- Shared dotted background with an opaque terminal viewport; an opt-in clipped shell frame.
- An optional keyboard with shifted legends, original arrow artwork, larger geometry and aligned Up/Down keys. Single taps use sticky modifiers.
- An isolated Yazi icon grid: arrows move through the grid, Enter opens, and Backspace goes up. See the full [file navigation guide](../FILE-NAVIGATION.md).
- Native process details through top, with popup focus protection for on-screen input.
- A dedicated local Kitty launcher and Arch package staging that leave normal user configs alone.

## Tested workflow

Use one local Kitty client with at least 140 columns by 40 rows. Kitty and the instrument workers must share the filesystem for tempfile graphics. The launcher selects that mode for its dedicated window. The keyboard starts hidden and the instruments target 24 FPS.

We reviewed Omarchy with Kitty 0.49.2, tmux 3.8, Python 3.14, Pillow 12.3 and Yazi 26.9.1. We also tested Ubuntu 24.04 with Kitty 0.32.2, tmux 3.4, Python 3.12 and Pillow 10.2 under WSLg. This first package targets Arch; we provide no Debian package.

From the source checkout, run python3 app.py. With the Arch package installed:

```sh
edex-ui-tui --cwd "$HOME"
# Controls from another terminal, using the same socket selector if you set one:
edex-ui-tui --toggle-keyboard
edex-ui-tui --install-shell-frame
```

After Ctrl-b, press 1–5 to switch shells, Shift-K to toggle the keyboard, Shift-P for process details, z to zoom or d to detach. Press q or Escape inside process details to close it. Read the [README](../../README.md) for argument and dependency details.

Before an upgrade, finish shell work and stop the project session with edex-ui-tui --stop. Stopping ends its shells. File replacement does not reload Python workers; launch a new session after upgrading.

## Limits

The native process popup remains rectangular. Its frame mask tracks the opening rectangle; moving or resizing it can expose overlap. The clipped shell frame remains opt-in.

Direct graphics transfer has known reattach failures. Multiple clients, mobile SSH clients, Mosh graphics and physical touch remain outside the tested workflow. Physical typing does not light up the keyboard. Multi-touch and held-key repeat are incomplete.

Rajdhani approximates the upstream display font. Startup choreography and audio remain incomplete, and the grid tile uses an integer approximation for a 1080px reference height. We have not established a performance advantage over Electron. Higher FPS targets are optional and do not guarantee displayed frame pacing.

## Validation and credits

The integration suites passed on both reviewed distros. We checked actual window resizing, a second font scale, raster equivalence and a ten-minute local run. The Arch recipe passed a clean chroot build, installed upgrade, graphical restart and removal.
